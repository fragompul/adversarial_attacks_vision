# Poisoning

Every other attack folder in this repo assumes the model is already trained and fixed, and only the input at inference time is under attack. This folder attacks a different stage entirely: training time.

01_BadNets implements Gu et al.'s 2017 backdoor attack: poison a small fraction of the training set with a fixed visual trigger and a wrong label, then fine-tune normally. The model learns two behaviors at once, correct classification on ordinary inputs and an override to a chosen target class whenever the trigger appears, planted into TrafficNet/GTSRB with a 24x24 magenta square in the bottom-right corner, relabeled to "Ahead only" for narrative consistency with the physical patch attack elsewhere in this repo. Clean accuracy comes out essentially untouched (73.0% versus a 70.2% baseline), so the backdoor is genuinely invisible under ordinary evaluation, but the backdoor's own potency (19.0% attack success rate on triggered, non-target images) lands well below the 90-100%+ regime the published literature typically reports, honestly attributed to the same reduced-scale limitation already documented in `defenses/04_adversarial_training.ipynb`: a small dataset and a baseline model that itself only reaches 70% clean accuracy. The effect is real, not noise (an untouched baseline shows exactly 0% false positives on the same trigger, and ASR nearly doubled between a first, weaker attempt and this one), just not yet saturated at this compute budget.
