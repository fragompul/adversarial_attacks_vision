# Semantic

Every other attack in this repo, without exception, works by adding something to a pixel's color value and bounding how much that addition can be. This folder implements an attack that never changes a single pixel's color at all.

`01_stAdv` implements Xiao et al.'s 2018 spatially transformed adversarial examples from scratch, including a differentiable bilinear image warp (the same operation a Spatial Transformer Network uses, here optimized to break a classifier instead of helping one) written directly against `tf.GradientTape` since nothing else in this repo needed one. A per-pixel displacement field is optimized against a margin-based adversarial loss plus a total-variation smoothness penalty on the field itself, so the resulting warp stays locally coherent, a gentle stretch, not scrambled pixels. Against MobileNetV2 on 5 MiniImageNet images, every single one was successfully fooled, with an average pixel displacement of under 1.5 pixels in every case, in one case under half a pixel. This is a genuinely different failure mode from every $L_p$-bounded attack elsewhere in the repo: the misclassification comes from where content sits in the frame, not from what color it is.
